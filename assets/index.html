How does it work?
corridor width
The rule of the game: the route must stay inside a band this wide around the straight line. The router follows the line as closely as the roads allow and pays a growing penalty for straying from it. Try 5 km for a strict line, 8–15 km for a doable one. If no route fits, the search tries slightly wider bands (at most +2 km) and lists those separately as looser-corridor alternatives.
activity
Which ways the router may use and how it weighs them. Road bike prefers smooth roads and avoids paths; paved only forbids anything unpaved. Gravel / MTB welcomes tracks and trails. Hike uses footpaths. Every activity avoids steep climbs and glaciers.
cross the country
Both ends sit at the border — the outermost roads of the loaded map — on opposite sides, so every suggestion is a true crossing. Any line instead samples lines anywhere, about the length you give.
A/B alternatives
Between two points you get up to three routes, from loose (shortest) to strict (hugs the line).
ranking
Lower score is easier: mostly how much longer the route is than the straight line, plus penalties for wide bulges, long ferry/lake hops and climbing. Elevation comes from the terrain data loaded at startup.
sharing
After a search, copy link (bottom right) gives a URL that re-runs exactly the same search.
